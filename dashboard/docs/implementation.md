# Meme Scout 实施计划

目标：本机浏览器自动监控小市值热门币，提供可核验排雷证据，不执行交易。

方案：Sites React 工作台 + 仅绑定 127.0.0.1 的 Node 数据服务。GMGN 使用项目内 CLI 与已有配置；Robinhood Trenches 使用其前端实际公开接口。服务每 60 秒发现候选，并在限流预算内逐个检查。每个数据源有时间、错误和原始响应。界面将风险、未知、未触发分开。

- [x] 数据适配：GMGN 热门、info/security/holders/created-tokens；RHT tokens、radar、flow；DexScreener 市值池子；GoPlus 与 Honeypot/RugCheck 交叉证据。
- [x] 测试先行：布尔字符串、税率单位、无数据非安全、模拟失败、LP vs 供应锁仓、有限钱包样本、重复 X 帖子、过期缓存和输入验证。
- [x] 监控：链选择、明确市值与流动性范围、未知市值不混入低市值列表；候选排序、串行扫描、缓存、暂停/恢复、失败继续、定时刷新。
- [x] 排雷：可增发/冻结/黑名单/代理/税；卖出模拟；LP 锁定比例与到期证据；持仓及共同出资样本；开发者发币历史，不以历史跌幅指认跑路。
- [x] X：有 Bearer Token 时按合约抓近 7 天样本；没有凭据时明确未连接。展示去重作者、复读、账号年龄、样本局限与原帖，不生成真人概率。
- [x] UI：深色行情工作台、自动候选列表、右侧证据详情、来源健康度、JSON 报告导出。无需 CA 输入。
- [x] 验证：Node 核心测试、TypeScript、生产 build、本机 HTTP 集成与真实候选扫描；交付本机入口与启动说明。

RHT 属第三方社区工具，链为 Robinhood 4663，buyers/holders/flow 仅为追踪的钱包子集；没有 marketcap，必须补齐 GMGN/DexScreener 后筛选。X 的样本统计仅表示可疑传播模式，无法证实真人身份。LP 锁定也无法证明未来可卖或价格稳定。

验证结果：18 项自动化测试、TypeScript、源码 lint 和生产构建通过；本机接口实测发现、扫描、暂停/恢复、切链/恢复、跨站拒绝和报告导出通过。npm audit 为 0 漏洞。X 接口已实现并测样本规则，但本机尚未配置 X Token，未声称已验证在线 X 读取。

## LIVE TAPE 增量（2026-09-06）

用户要求把官网实时交易中的 FOMO 交易员记录用于自动扫币。

- [x] 核验官网 app.js 和实际 `/api/tape`：数组、事件 ID、秒级 ts、cash_leg 定价、异常 flags、钱包/CA/主页区分。
- [x] 独立 5 秒重叠轮询；每 60 秒重读 400 行以接收较早修订；去重、畸形修订撤销、补抓窗口缺口提示。
- [x] 最近 120 秒合格买入经 DexScreener 市值/流动性核验后自动入队；最多 10 个优先位置，候选总数 40；历史触发候选最多观察 15 分钟，失去 2 分钟优先权后按普通候选处理。
- [x] UI 增加交易流、过滤、FOMO/浏览器链接、地址复制、候选跳转和触发买入证据。
- [x] 自动化覆盖重复/修订/异常/缺字段、报价过滤、暂停与切链竞态、2:1 公平扫描、缓存与失败退避。

验证：37 项测试通过；新增来源已用实时接口确认返回正常，超出默认市值范围的买入只进入观察表。本机页面 HTTP 200，状态接口取得 400 条记录，连续读取确认交易流时间戳持续推进。TypeScript、源码 lint 和生产构建通过。没有修改风险报告 180 秒新鲜度定义，也没有增加交易执行功能。
